# NFC 手动交接与相机标签

日期：2026-11-06。用户明确选择两种功能：手机 / 平板碰一碰转交任务，以及给相机贴 NFC 标签触发连接。两种均已实现，本次交付为可覆盖此前本地版本的 ARM64 NFC 试用 APK；尚无 NFC 手机、标签或相机实测。

**本次是 NFC 手动交接，不包含手机间持续 BLE 协调、组内自动选举或按电量自动切换。** 相机位置继续通过原有 Sony BLE 链路发送。自动协作仍按[多设备方案](2026-11-06-multi-device-handoff.md)另行开发，不能把 NFC 接口当作已完成的自动协作功能。

## 使用入口

设置 → **NFC 设备交接与相机标签**。提供简体中文和英文，其他语言使用英文回退。设备仍须先在 AlphaGPS 中完成 Sony 相机配对，NFC 不能复制另一台手机的 Bluetooth 配对密钥。

### 两台设备碰一碰

1. 两端安装同版本 APK，先分别配对同一台相机。开启 NFC，保持解锁、界面在前台。接收端开启蓝牙、系统定位，并授予位置和附近设备权限；近似位置也可用。
2. 当前负责设备在 NFC 页面选中相机，选择“转交选中的相机”。已停用或已交出的相机须先明确重新启用；不能把关闭应用误当成仍在负责。
3. 接收端选择“接收另一台设备的相机”，贴近一次以读取相机标识。这一步不会暂停旧机。
4. 接收端确认相机后，再次贴近同一发送端并保持接触。发送端先持久保存暂停状态、停用这台相机、清理位置和排队任务，尝试释放位置端点，关闭它的 GATT 连接。
5. 接收端收到“旧机已暂停并关闭本地连接”的确认后，才启用本机这台相机并请求连接。回到相机列表检查定位与连接，并通过原图 EXIF 核对结果。

发送端需要 HCE 卡模拟，接收端需要兼容的 ISO-DEP 读卡能力。并非所有 Android 平板都具备 NFC / HCE；没有相应硬件时会显示说明，原有定位和蓝牙功能不受影响。两端 NFC 天线位置、手机壳、钱包优先级和不同厂商系统仍须实测。不能依赖已经弃用的 Android Beam。

发起端本地连接关闭不等于 Sony 已接受下一部手机，也不等于照片已有 GPS。交接可能存在获取位置或握手的空窗，没有无缝接管保证。

若触碰中断，原接收端可在同一交接仍有效时重试；另一接收端不能重复领取。若关闭页面、过期、进程结束或新设备最终连接失败，旧机可能已暂停，**不会自动恢复并争抢相机**。恢复前确认另一端没有继续发送，再在旧机设备列表手动启用相机。重新安装或重启接收界面丢失确认凭据时，也需检查两端状态后重新发起。

### 相机 NFC 标签

1. 在 NFC 页面选中已配对相机，选择“写入选中的相机（覆盖标签）”。将自己的可写 NDEF 标签贴近设备，原内容会被替换，标签不会被锁成只读。
2. 写入记录仅含版本和相机 MAC 标识，以及 AlphaGPS 应用记录；不包含坐标、位置轨迹、Bluetooth 密钥或持久交接授权。版本 1 相机载荷为 11 字节。
3. 之后可在解锁状态触碰标签，由系统打开 AlphaGPS 的连接确认页；也可在 NFC 页面选择“读取相机标签”。确认后检查本机配对和权限，再请求连接。

建议使用可写 NTAG213 / 215 / 216 等兼容 NDEF 的标签；程序会检查容量、只读状态和格式支持。相机金属机身附近通常要使用抗金属标签。相机原有的 Sony NFC 标记不等于可供 AlphaGPS 改写的标签。

**静态标签不能暂停另一部手机的位置链接。** 标签确认页会说明先停止另一发送端，不把标签当作所有权证明；若要让另一台设备自动暂停，请使用设备间两次触碰的交接流程。

## 稳定性与功耗边界

- `android.hardware.nfc` 和 `nfc.hce` 均为可选；只新增普通 NFC 权限，没有新增 BLE 扫描 / 广播权限、SDK、云服务、WakeLock 或热点。
- 读卡模式仅在明确选择接收 / 标签读写后启用；离开前台立即关闭，最多两分钟自动关闭。卡模拟交接也最多两分钟，离开界面即撤销入口。NFC 页面本身不启动定位。
- 只有已明确提交的旧机暂停动作会在界面关闭后继续做有界清理。Wi-Fi 清理和位置端点释放分别最多等两秒，随后关闭 GATT；不因取消界面把旧机重新启用。
- 暂停状态使用 SharedPreferences 的 `commit()` 返回值确认持久化；只有持久化成功并移除 GATT handle 才回报可接管。这里需要 Boolean 返回值，不能直接换成返回 Unit 的 KTX edit。
- 连接入口和实际 BLE 写入路径都检查暂停门禁，覆盖迟到的 always-on 列表、CDM 唤起、重启和旧队列。被暂停设备只允许最后的 DD30 释放写入，不允许重新启用位置或继续发送。
- 停用这台相机同时更新现有设备开关，手动重新启用会解除暂停。明确重新配对也可解除门禁；普通广播出现不会解除。转交一台相机时，其他相机继续工作。
- NFC HCE 服务属于 `other` 类，要求解锁，并由 `BIND_NFC_SERVICE` 保护。应用不注册为支付钱包；仅在转交页面申请前台偏好，离开即撤销。
- 导出的标签入口把 Intent / NDEF 视为不可信输入，严格检查固定版本、载荷长度、相机标识和本机配对，并要求用户确认；不执行标签 URL 或任意应用命令。

卡模拟使用应用专用 AID `F053415347505301`。交接随机凭据与接收端随机凭据各 16 字节，提交后只允许同一领取方重试。无需也不使用可变的 NFC UID 来认证身份。这是用户明确开启的近距离任务交接，不是远程设备身份认证或完整协作组配对。

手机采样仍请求每 60 秒一次，相机目标每 5 秒刷新，样本真实年龄最多 90 秒。NFC 未改变这些节奏；没有测得 NFC 或整个 app 的电流，不能承诺具体续航收益。

## 实机验收

1. 两台设备成功交接后，旧机锁屏、重启、相机开关均不应抢回；确认旧机开关为停用。
2. 分别在第一次读取、第二次提交、旧机暂停后移开设备；检查重复贴靠和恢复说明，不应出现第三台重复领取。
3. 接收端未配对、权限撤回、仅近似位置、关闭系统定位 / 蓝牙时，不能提前暂停旧机。
4. 写空标签、覆盖测试标签、读只读 / 小容量 / 不兼容标签；正常读取仅连接自己已配对的相机。
5. 关闭 NFC、设备没有 NFC、无 HCE、页面退后台、读写等待超过两分钟；原有单机定位路径继续可用，读卡不常驻。
6. 在 Sony 实机上交接前后连续拍照，检查 JPEG / ARW 原图 GPS，区分本地暂停确认、GATT 写成功和 EXIF 三个结果。
