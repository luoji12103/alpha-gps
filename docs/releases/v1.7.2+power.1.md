# Alpha GPS v1.7.2+power.1

本项目首次 Power 正式版，Android ARM64 FOSS，versionCode **173**。独立 fork，原作者为 Saschl 与贡献者，继续遵循 GPL-3.0。

## 基础版本

同步到上游 `ec4dae727205136d1fb0a3574246ed026d012a43`，包含 11 月 6 日之后的 4 个官方提交（相机设置分组、翻译、网站依赖）。源码版本为 **v1.7.2**；截至发布时官方最新 tagged release 仍为 **v1.7.1**。本次是本分支的正式版，不是宣称官方 v1.7.2 已发布。

## 已实现

- 每 60 秒请求新位置，与相机目标每 5 秒刷新分离；有效坐标可以重复发送，真实位置年龄超过 90 秒则停止重发。
- 定位注册恢复采用有界重试；没有相机需要位置时释放定位，关闭不需要的日志格式化。
- NFC 手机 / 平板手动交接：读取 → 确认 → 第二次贴靠提交。旧设备持久暂停这台相机并关闭本地连接后，新设备尝试接管。
- 可写 NFC 相机标签：触碰后经确认请求连接；普通标签不能暂停另一台设备。
- Android 内显示完整 `+power.1` 版本和中文 / 英文更新说明；修订比较可识别 power 数字后缀。
- 主页与 Release 使用本分支入口、固定下载文件名、校验值和明确的版本规则。

## 不包含与验证边界

按电量 / 在线状态自动切换、持续设备协调仍未实现。NFC 需要兼容硬件，两端须分别先配对相机；不承诺 Sony 已接受新位置来源或无缝接管。

本版共享层 **435** 项、Android **34** 项，合计 **469 项测试通过**，0 失败 / 错误 / 跳过。FOSS Release 构建、release lint 与 GPlay Kotlin 编译通过；lint 0 错误、20 项非阻断警告。Node 24 主页构建通过，静态资源路径和无客户端 JavaScript 已检查。完整检查结果和 APK 摘要随 Release 的 `BUILD-INFO.json` 发布。

没有可用实体 Android / NFC / Sony 设备：未实测碰靠、标签写入、安装、接管、原图 EXIF 和实际功耗。5 秒是当前刷新策略，Sony 未公布跨机型通用的最大允许间隔。

## 安装

Android 8.0+，**arm64-v8a**，不含 GMS / Sentry。沿用此前试用包签名，可直接覆盖同签名本地版本；与官方商店 / F-Droid 签名不同。

设置 → **NFC 设备交接与相机标签**。操作和恢复方法见 [NFC 指南](../audits/2026-11-06-nfc-handoff.md)。

后续同基础版本依次发布 `+power.2`、`+power.3`，合并官方新基础后更新前半部分；Android 内部版本号一直递增。
